Capturas reales tomadas el 24 de noviembre de 2026, ejecutando el código del repositorio (base `2caba248`) mediante Wrangler local en un navegador.

Se utilizó una D1 local nueva y aislada, con ocho citas ficticias y teléfonos vacíos. El nombre del salón se configuró como «CitaSalón · Demo». La persona escrita en el formulario también es ficticia; el formulario no se envió.

Las imágenes son capturas directas del navegador, sin generación por IA, composición ni retoque de la interfaz. Se usaron los controles reales para seleccionar el tema claro y el horario del formulario. Los tamaños corresponden a las vistas de escritorio y móvil del navegador, no a dispositivos físicos.

No se conectó Meta ni se utilizó una base de producción. Los importes son datos de ejemplo calculados por la aplicación.
